## Workflow

- Keep each change small and work on a dedicated task branch.
- Open a pull request; a different team member must review the changes before merging.
- Record at least one actionable review observation and the author's response.
- Run the relevant local checks before pushing changes.
- Verify GitHub CI results on the latest pushed revision before merging.
- Never commit `.venv`, generated artifacts, tracking databases, credentials or private reports.
